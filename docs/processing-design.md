# V1.2–V2.0 设计与交付范围

日期：2026-11-05。继续沿用本地图片会话、三栏工作台、CSS Modules 与 Worker 渲染，新增 `#transform`、`#convert`、`#batch` 三个独立入口。原拼接和水印保留。

- V1.2：单张选择；自由/固定比例裁剪、原图上的拖动选区和百分比输入；等比/自由缩放、四个直角方向、水平/垂直翻转；PNG/JPEG 生成、实际体积与变化、重置、取消和重试。
- V1.3：独立 PNG/JPEG/WebP/AVIF 转换；解码和编码能力分别检测；所有输出核对 MIME、签名及重新解码尺寸。WebP/AVIF 必要时动态加载本站托管的 jSquash WASM，不向第三方发送图片。PNG 不显示质量调节。
- V2.0：逐图有序执行裁剪、缩放、旋转/翻转、水印、编码；步骤可独立启用；原始文件不变。开始时冻结参数和素材引用。取消保留成功项，错误/取消项可重试，显示结果清单、实际字节和命名规则。
- ZIP 使用存储模式，图片已经编码，不再压缩；按 Blob 流计算 CRC32，避免同时读取全部文件。可取消，累计结果及 ZIP 有明确预算，文件名清理并去重。
- 版本化 JSON 模板可保存到 localStorage、下载及重新导入；仅保存参数，绝不持久化图片、Logo 或处理结果。图片水印模板明确要求重新选择 Logo；未知版本、错误参数和过大模板均拒绝，保留当前配置。禁用 localStorage 时仍可使用文件迁移。

## 工作台结构

左侧共用素材；中间展示当前选择的图片和处理结果；右侧显示当前工具的设置。批量右侧展示按顺序执行的步骤开关及命名规则，底部显示批次进度和成功/失败结果。手机单列、设置可折叠，导航允许横向滚动。

裁剪坐标针对方向归一化后的原图，以百分比保存，固定比例在选框内居中收缩；导出先裁剪、缩放，再旋转与翻转，最后在最终方向上绘制水印。预览和导出使用同一几何计划。预览使用缩略源，导出使用原图。

## 预算和能力

沿用现有源图/输出预算；批量累计 Blob 限制为桌面 32 MiB、粗指针设备 16 MiB，ZIP 再检查累计大小。AVIF 另限制输出为桌面 400 万/粗指针 150 万像素，并预留编码器内存；这些是产品保护值，不是设备安全承诺。无法编码时显示真实原因，不允许错误后缀下载。

AVIF 输入仅接受经过容器尺寸预检的静态直接编码主图；动画、网格及需要方向变换的 AVIF 明确拒绝。解码依赖当前浏览器实际能力，不在导入前无界加载解码器。

依赖依据：[jSquash 官方仓库](https://github.com/jamsinclair/jSquash)，具体行为以锁定版本源码和生产构建浏览器验证为准。
