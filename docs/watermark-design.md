# V1.1 图片水印设计

日期：2026-11-05。范围为文字水印、图片水印及同一配置的批量处理；保留 V1.0 拼接工作台。图片处理、格式转换、ZIP 和可组合批量队列仍属后续版本。

## 工作台与视觉

沿用浅灰画布、白色面板和蓝紫强调色。顶部增加“图片水印”导航，使用 `#watermark` 直接进入。桌面仍为素材、预览、参数三栏，预览下方放生成入口与结果列表；平板参数移至下方；360px 手机将素材和参数折叠，工具导航保持可见。

素材在两个工具之间共用；布局参数与水印参数分别保留。切换工具不会清空图片或结果。水印预览通过选择框切换当前素材，不把多张图片拼在一起。清空素材需确认，原始文件保持不变。

| 区域     | 内容                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 左侧素材 | 现有添加、拖入、粘贴、排序、错误与清空流程                                                           |
| 中央预览 | 单图选择、适应窗口、实时水印、输出原始尺寸；空状态含示例入口                                         |
| 右侧参数 | 文字/图片类型、内容或 Logo 导入、九宫格位置、相对大小、边距、透明度、旋转、平铺间隔、PNG/JPEG 与质量 |
| 底部结果 | 开始生成、真实逐项进度、取消；每项尺寸、体积、成功/失败/取消、下载和单项重试                         |

## 参数与绘制规则

- 文字默认“© 我的作品”，系统无衬线/衬线字体、白色、透明度 60%、右下、旋转 0°；提供颜色选择。文字最多 80 个字符，空白内容阻止生成。
- 大小以图片短边的百分比表示：文字为字号（1–20%），图片为宽度（5–60%）；Logo 保持比例，过高时缩小至画面内。
- 边距为短边 0–20%，九宫格锚点以旋转后的外接矩形计算，尽可能保持水印在画面内；超长文字等比缩小并完整显示。
- 旋转范围 −90° 至 90°，以水印中心旋转。平铺按旋转后的外接矩形和短边百分比间隔排布；限制数量，防止密集平铺阻塞。
- PNG 保留源图与 Logo 透明度；JPEG 使用明确的白色底色。下载以原文件名加“水印”和序号命名，后缀由实际编码决定。
- 预览与导出使用同一绘制函数和原图坐标。预览仅缩小底图，Logo 使用同一原始 Blob；导出重新读取原图。
- 中文文字绘制在主线程等待 `document.fonts.load` 和 `document.fonts.ready`，预览/导出使用同一字体上下文，避免 Worker 字体回退差异。Logo 路径可以使用既有 Worker；不新增远程字体和图片请求。字体外观随设备变化。

字体等待与中心旋转分别依照 [FontFaceSet.load](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/load) 和 [Canvas rotate](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/rotate) 的 API 契约实现。

## 任务、失败与资源

共用格式头检查、EXIF 方向归一化、顺序导入、源图/输出预算、编码签名与重新解码校验、下载和资源释放。Logo 独立导入并沿用同一文件限制，替换失败保留上一张有效 Logo。

批量生成在点击时快照参数、素材顺序和 Logo；编辑仅影响下一次任务。一次绘制一张，单项失败继续后续项。取消立即停止后续项，忽略当前不可中断调用的迟到结果，保留已经完成的结果。失败或取消项可单独重试，按该批次原配置生成，界面明确提示。

结果只保留在会话内，桌面累计 Blob 上限 64 MiB，粗指针设备 32 MiB；超过时给出分批处理提示。重新生成替换旧结果；提供单独清空结果入口；下载逐项触发，不自动触发多文件下载。清空素材不删除已生成结果。刷新释放所有图片与结果，不持久化文字、Logo 或原始文件。

## 验收

先检查参数归一化、九宫格/旋转/平铺几何，再在 Chromium、Firefox、WebKit 验证实际 PNG/JPEG 文件：尺寸、像素、透明度、中文文字、Logo、预览一致性、部分失败、取消与重试、任务快照、工具切换、降级和无外发。360/768/1440px 检查溢出、键盘和 axe 自动化无障碍，并保存截图。真实手机保存及触控行为单独标为未验证。
